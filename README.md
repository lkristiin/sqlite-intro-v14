## Смысл полей таблицы exhibits 
* **id** (INTEGER PRIMARY KEY) - номер записи; не вводится вручную при добавлении.
* **name** (TEXT) - название экспоната.
* **category** (TEXT) - материал.
* **value** (INTEGER) - год изготовления.
